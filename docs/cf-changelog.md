# Changelog

## 0.1.08

### Changed

* The 2i Crafting CPU now exposes all six faces as AE2 machine connections, so AE2 cables can
  attach on any side and the CPU can pass the network channel through in every direction.

## 0.1.07

### Added

* Anti-proton nucleosynthesizing fallback for 2i (4). When Mekanism Sun is not installed but
  Mekanism is, `2i (3) + 8 mB antimatter` now produces `2i (4)`. When Mekanism Sun is present,
  its assembler recipe remains the only 2i (4) recipe.

## 0.1.06

### Added

* The 2i material chain: `2i`, `2i (2)`, `2i (3)` and `2i (4)`, all fire resistant.
* Optional Mekanism silica chemistry, with a vanilla smelting fallback when Mekanism is absent.
* The Infinite ii Cell, an AE2 storage cell with infinite extraction for 2i, sand and the
  16 vanilla concrete powders.
* The 2i Crafting CPU, a single-block AE2 crafting CPU with an editable byte-based storage pool.
* TNT drops and optional AE2 Lightning Tech behaviour.
